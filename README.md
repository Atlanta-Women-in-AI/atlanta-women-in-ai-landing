# Atlanta Women in AI - Modern Website Redesign

A cutting-edge, single-page website redesign for Atlanta Women in AI that captivates visitors with modern animations, glassmorphism effects, and an intuitive user experience.

## 🚀 Project Overview

This is a complete modern redesign of the Atlanta Women in AI website featuring:
- Single-page application with smooth scrolling
- Dynamic animations and particle effects
- Glassmorphism design elements
- Interactive 3D flip cards
- Responsive design for all devices
- Modern gradient color scheme that "oozes swag"

## 🎨 Design Features

### Hero Section
- Animated gradient mesh background
- Interactive particle animation with node connections
- Staggered title reveal animation
- Live statistics counters with smooth animations
- Animated scroll indicator

### About Section
- Mission statement with glassmorphism effect
- Floating AI-themed cards with continuous animations
- Interactive value proposition cards

### Why Join Us (Initiatives)
- 3D flip cards showcasing all 6 initiatives
- Content merged from original Initiatives page
- Touch-friendly for mobile devices
- Hover effects with smooth transitions

### Events Section
- Featured event card with real-time countdown
- Upcoming events calendar
- Quick registration CTAs
- Glassmorphism styling

### Additional Features
- Auto-rotating testimonials
- Three clear engagement pathways
- Sticky navigation with progress indicator
- Mobile-responsive hamburger menu

## 🛠️ Technologies Used

- **HTML5**: Semantic markup
- **CSS3**: Modern features including:
  - CSS Grid & Flexbox
  - Custom Properties (CSS Variables)
  - Backdrop filters for glassmorphism
  - Complex animations & transitions
- **Vanilla JavaScript**: No dependencies
  - Intersection Observer API
  - Canvas API for particles
  - Smooth scroll implementation
